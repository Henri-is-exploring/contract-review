# 合同审核要点手册（法务视角）

> 本文件是合同审核 Skill 的核心知识库。审核任何合同时，严格按照「整体 → 内容 → 格式」三个阶段逐项检查，不得跳过阶段。
> 每条要点均为可执行的检查项：先判断是否命中，命中则给出【风险说明】和【修改建议】。

## 审核总原则

1. **先定立场，再审条款**：同一条款对甲方和乙方的风险完全不同。若用户未说明己方身份，必须先询问；无法确定时，分别从甲方、乙方两个视角给出分析。
2. **悲观心态**：审核违约责任等条款时，始终假设"对方违约了、发生了对我方最不利的情况"，检验合同能否保护我方利益。
3. **明确可执行**：凡表述模糊、无法直接执行的约定（时间、金额、标准、地点、程序），一律视为风险点。
4. **权利义务对等**：只约束一方的条款必须提示，违约责任不能只约定我方。
5. **对抗视角贯穿全条款**：不只违约责任——对付款节点、质保保修、保密、终止与续约、转包/分包等每一类条款，都先做"对方严格按此条款行权、我方处于最不利情形"的推演，检验我方是否被实质损害；只要损害成立即列为风险点，不因其非"核心条款"而放过。

---

## 阶段一：整体审核

### 1. 确定己方立场（三个判断）

| 判断 | 方法 | 对审核的影响 |
|---|---|---|
| 甲方还是乙方 | 双方在交易中的角色 | 决定审核重心：付款方重点审交付/验收，收款方重点审付款条件 |
| 强势方还是弱势方 | 谁更想促成交易，谁相对弱势 | 弱势方谈判空间小，审核时优先守住底线条款（付款、违约、解除），次要条款可适当让步 |
| 核心目的 | 长期合作还是一次性交易 | 长期交易更能容忍风险；一次性交易追求短期利益，应从严审核 |

### 2. 摸清合同框架（递进四问，缺一不可）

1. **交易类型**：买卖、承揽、租赁、服务等——决定适用的法律规则和惯例
2. **谁给谁什么**：双方核心权利义务各是什么
3. **怎么给、什么时候给**：付款/交付节点、验收安排
4. **不给怎么办**：违约责任、争议解决方式

## 阶段二：内容审核（分章节、分条款）

### （一）合同主体

- [ ] 主体是否真实存在（核对企业名称、统一社会信用代码）
- [ ] 信息是否准确（名称全称、法定代表人等与实际一致）
- [ ] 主体状态是否正常（存续、未吊销注销、无重大经营异常）
- [ ] 地址是否明确（关系到通知送达与管辖）

#### 审核经验积累
- [ ] 主体名称须使用全称并核验统一社会信用代码，避免简称导致主体认定争议（来源：2026-08-09 合同审核）
- [ ] 房屋租赁须核验出租方产权证/身份证原件，确认非二房东代签，避免合同无效（来源：2026-08-09 合同审核）

### （二）双方权利义务

- [ ] 是否对等：是否存在明显不公的霸王条款（如免除己方全部责任、加重对方责任、排除对方主要权利）

#### 审核经验积累
- [ ] 承租方合同应增补：同等条件优先承租权、买卖不破租赁（转让通知+合同继续履行）、出租方进入须提前通知并征得同意（来源：2026-08-09 合同审核）
- [ ] 承租方合同应增补：同等条件优先购买权、买卖不破租赁、出租方进入须提前通知并征得同意（来源：2026-08-09 合同审核）
- [ ] 定制/委托开发成果IP归属应按“谁提需求谁付费”反转，避免委托方被技术锁定；使用许可应含自行实施及再许可权（来源：2026-08-09 合同审核）

### （三）款项支付与标的物交付

**款项：**

- [ ] 金额：大小写是否一致；是否含税、税率多少
- [ ] 支付时间：是否明确可执行；若与交付挂钩，须明确是"先款后货"还是"先货后款"
- [ ] 支付方式：银行转账/微信/支付宝/现金；收款账户是否准确；是否允许分期付款

**标的物（须明确可执行，按类型分别核对）：**

- [ ] 动产：名称、规格、型号、性能参数
- [ ] 不动产：名称、具体坐落地点
- [ ] 知识产权：性质、名称、权利状况、有形载体
- [ ] 行为（服务）：名称、性质、范围、实施方式

**数量：**

- [ ] 计量单位、计量方法、具体数目是否明确
- [ ] 避免模糊表述（如"一批""若干"）
- [ ] 需通过计算确定的，是否写明计算标准与依据

**质量：**

- [ ] 质量标准是否明确：国际标准/国家标准/行业标准/地区标准
- [ ] 是否约定质量检验方法、责任期限、异议提出期限及处理方式
- [ ] 复杂标的是否在附件中列明技术参数、验收标准

**交付：**

- [ ] 交付时间是否明确可执行（具体日期或确定的计算方式）
- [ ] 交付方式：送货上门/上门取货/快递
- [ ] 风险转移：运输/交付过程中发生毁损灭失，风险由谁承担

#### 审核经验积累
- [ ] 金额须大小写并列、注明含税及税率，开票类型与时限明确（来源：2026-08-09 合同审核）
- [ ] 押金须约定明确返还期限及逾期责任；租赁税费本质为出租人收入税，应约定由出租方承担（来源：2026-08-09 合同审核）
- [ ] 押金须约定明确返还期限及逾期责任；租赁税费本质为出租人收入税，应约定由出租方承担（来源：2026-08-09 合同审核）
- [ ] VMI寄售模式下，领用即转移所有权与付款时点、未领用物料仓储费标准须书面明确，最低保有量应双方协商而非供应方单方决定（来源：2026-08-09 合同审核）
- [ ] 预付款比例须以明确的总额基数为前提，总额未填时预付款条款不可执行（来源：2026-08-09 合同审核）

### （四）违约责任（核心条款，从严审核）

- [ ] **违约情形**：是否列举常见违约行为（逾期付款、逾期交货、质量不合格等）并逐一设置对应处理方式
- [ ] **责任形式**：继续履行、赔偿损失、定金罚则、违约金——是否覆盖
- [ ] **违约金合理性**：比例是否符合市场惯例；过高影响交易、可能被调减，过低无法弥补损失
- [ ] **核心目的的强保护**：涉及合同核心目的的违约（如节日活动的节庆物资逾期交付，错过即无意义），应设置更强的责任，如单方解除权
- [ ] **赔偿范围**：是否明确直接损失、预期利益损失
- [ ] **维权费用**：是否约定律师费、诉讼费等由违约方承担
- [ ] **责任对等**：不能只约定我方违约责任而无对方违约责任；计算口径（如"合同金额"指总价/首付款/尾款、"日"指自然日/工作日）必须明确
- [ ] **免责/限责情形**：若条款限制我方索赔，检查是否可争取免责情形列举（如因甲方未及时确认图纸导致乙方逾期，乙方不承担违约责任）

#### 审核经验积累
- [ ] 违约责任须双向约定且计算口径（基数、日/工作日）明确，禁止单边约束（来源：2026-08-09 合同审核）
- [ ] 租赁违约须双向对等：除逾期付租违约金外，须约定出租方提前收房/无故解约的退租退押+违约金+损失赔偿（来源：2026-08-09 合同审核）
- [ ] 违约赔偿上限须明确基数（总租金）并排除根本违约/故意，且建议约定维权费用（律师费/诉讼费）由违约方承担（来源：2026-08-09 合同审核）
- [ ] 违约赔偿上限须明确基数（总租金）并排除根本违约/故意，且建议约定维权费用（律师费/诉讼费）由违约方承担（来源：2026-08-09 合同审核）
- [ ] 违约金须双向对等（基数、日利率、封顶口径一致），禁止单边高罚我方、低罚对方；免责/限责封顶须排除根本违约与故意（来源：2026-08-09 合同审核）
- [ ] 警惕“未反对视为同意/视为合格”等沉默推定条款，单方变更或免责风险高，建议删除或改为需书面确认（来源：2026-08-09 合同审核）

### （五）特殊条款

**不可抗力：**

- [ ] 定义：不能预见、不能避免且不能克服的客观情况（地震、台风、战争、疫情等）
- [ ] 处理程序：通知义务、证据提交要求与时限
- [ ] 责任划分：损失承担方式（通常各自承担）

**保密条款：**

- [ ] 保密信息范围：定义并列举（商业秘密、技术资料、交易信息等）
- [ ] 保密期限：是否覆盖合同终止后
- [ ] 接触人员范围：哪些人员负有保密义务
- [ ] 违反保密义务的具体违约责任

**知识产权条款：**

- [ ] 交易成果的知识产权归属及申请权归谁
- [ ] 若只有使用权：使用期限、地域范围如何约定
- [ ] 许可类型：独占许可/排他许可/普通许可
- [ ] 侵权保证：是否保证不侵犯第三方知识产权，侵权责任如何承担

#### 审核经验积累
- [ ] 不可抗力须严格限于“三不能”客观情况，禁止将上游停产、原材料短缺、成本上升等商业风险纳入，否则配合顺延免责严重失衡（来源：2026-08-09 合同审核）

### （六）争议解决

- [ ] **仲裁与诉讼只能二选一**，同时约定或表述不清的条款无效风险极高
- [ ] 仲裁：快速、保密，但费用高、一裁终局无救济
- [ ] 诉讼：耗时久、公开，但费用相对低、可上诉
- [ ] 管辖地：争取约定由我方所在地法院/仲裁机构管辖
- [ ] **高危写法**："向有管辖权的法院起诉"等于没有约定，必须提示改为具体管辖地

#### 审核经验积累
- [ ] 管辖须约定具体法院或仲裁机构，禁用「有管辖权的法院」等无效表述（来源：2026-08-09 合同审核）
- [ ] 承租方应争取管辖约定在房屋所在地法院，避免约定出租方住所地法院增加维权成本（来源：2026-08-09 合同审核）
- [ ] 承租方应争取管辖约定在房屋所在地法院，避免约定出租方住所地法院增加维权成本（来源：2026-08-09 合同审核）
- [ ] 管辖须约定我方所在地或约定仲裁，禁用对方所在地法院及“有管辖权的法院”等无效表述（来源：2026-08-09 合同审核）

### （七）生效与送达

- [ ] 生效条件：签字盖章生效，还是需要特殊审批程序
- [ ] 送达条款：是否约定明确、有效的送达地址（含电子送达方式）

## 阶段三：格式与程序审核

- [ ] 合同名称是否反映合同性质（如买卖 vs 承揽，影响法律适用）
- [ ] 合同编号是否与其他合同重复
- [ ] 是否存在错别字、前后表述不一致
- [ ] 附件：是否全部在正文中被提及；附件序号是否按正文出现顺序排列；附件内容是否明确可执行
- [ ] 交叉引用是否正确：如"见 1.3 条定义"，需核对 1.3 条确实是定义条款
